User Management App (React + TypeScript)
Project Overview

A simple React + TypeScript app that fetches and displays a list of users.
Demonstrates:

Getting Started
Install dependencies
npm install

Run the app
npm start

Open http://localhost:3000
to view it.

Tools & Libraries

React + TypeScript: Strong typing & modern React

Axios: Fetch API data

MUI: Material UI components

React Router (optional): Page navigation

React Query (optional): Data fetching & caching

Approach

Fetch users from https://jsonplaceholder.typicode.com/users using Axios.

Store data in local state (useState) and display via MUI cards.

Optional: Implement sorting, pagination, dark mode toggle, and React Router navigation.
